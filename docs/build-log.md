# Build Log

A dated diary of the project. Newest entries go at the **top**. Write a few lines every time you work on the project, even if it's "printed the arm, it warped, need a brim". The failures are the most valuable part of a portfolio.

**Entry template**

```
## YYYY-MM-DD — short title
**Did:** what I worked on
**Learned:** what surprised me / what I'd do differently
**Next:** the next concrete step
**Links:** commits, issues, photos, files
```

---

## 2026-11-19 — Project kickoff

**Did:** Started the project. Collected inspiration photos of rocket-style speed drones (Red Bull chase drone by Dutch Drone Gods, a white rocket-body build, a dark stealth-style build with nacelle motors). Set up this GitHub repo and its folder structure.

**Learned:** The fast drones all share the same idea: a slender fuselage carrying the battery and electronics, with the motors moved out onto short wings so the body can fly almost horizontal at speed instead of tilted like a normal quad.

**Next:**
- Research current speed records and what made those drones fast
- Pick a first motor/prop/battery combo using `analysis/sizing/top_speed_estimate.py`
- Sketch v0.1 concept in Fusion 360
