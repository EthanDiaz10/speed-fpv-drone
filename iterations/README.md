# Design Iterations

Each design version gets its own folder: `v0.1-concept`, `v0.2-first-print`, `v0.3-...`. The goal is a clear story of how the design evolved.

Rules of thumb:
- **New version = something meaningfully changed** (shape, motor layout, material, electronics)
- Each folder has a `README.md` copied from [TEMPLATE.md](TEMPLATE.md)
- CAD files for that version live in `cad/<version>/`, CFD in `cfd/cases/<version>-.../`
- Never delete an old version. Bad versions are part of the story.
